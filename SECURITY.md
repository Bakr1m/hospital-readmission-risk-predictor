# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a vulnerability

This is a portfolio project with no production deployment of real patient data.
If you find a security issue (e.g., dependency vulnerability, unsafe
deserialization, exposed secrets), please open a GitHub Issue titled
`[SECURITY]` with details and a minimal reproduction. Do not include any
real patient data.

Note: the training data used here is the public, de-identified UCI
"Diabetes 130-US hospitals" dataset — no PHI is involved.
